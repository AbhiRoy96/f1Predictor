# Security Policy

Maintaining the security and reliability of this project protects users, data pipelines, and downstream analytics.

## Supported Versions

Security updates and patches are applied to the latest code on the default branch (`main`) and active maintenance branches.

| Version / Branch            | Supported          |
| --------------------------- | ------------------ |
| `main` (current release n)  | :white_check_mark: |
| `maintenance/v0.1` (n-1)    | :white_check_mark: |
| Older releases              | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data exposure issue, please report it responsibly:

1. **Private Disclosure**: Do not open a public issue or discussion for sensitive security vulnerabilities.
2. **Contact**: Email the project maintainer at `royabhishek967@gmail.com` with the subject line `[SECURITY] F1 Predictor Vulnerability Report` or use GitHub Private Vulnerability Reporting if enabled on the repository.
3. **Report Details**: Please include:
   - A clear description of the vulnerability.
   - Steps to reproduce or proof-of-concept code.
   - The potential impact and affected components.
   - Any proposed mitigations or fixes.

## Response Process

- We will acknowledge receipt of your vulnerability report within 48 to 72 hours.
- We will evaluate the report, verify the impact, and coordinate a fix.
- Once a remediation is developed and tested, a security patch will be released.
